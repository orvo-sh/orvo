# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.
Email `security@orvo.sh` with a description of the issue, affected versions,
reproduction steps, and any known impact.

We will acknowledge the report, investigate it, and coordinate remediation and
disclosure with the reporter. Do not include live credentials, ingestion keys,
customer telemetry, or other sensitive data in the report.

## Supported versions

Until Orvo reaches a stable release, security fixes are applied to the latest
version on `main` and included in the next published release.
