# Changelog

All notable Orvo Agent changes are documented here. Releases follow semantic
versioning while the project is pre-1.0.

## Unreleased

## 0.1.0 - 2026-08-05

### Added

- Curated OpenTelemetry Collector distribution for Linux host metrics.
- Automatic one-time enrollment with dedicated Orvo ingestion credentials.
- Persistent on-disk export queue with retry and bounded memory usage.
- Linux amd64 and arm64 installation through a systemd service.
- Management commands for local development, status, diagnostics, and removal.
- Checksummed release archives and GitHub build-provenance attestations.
