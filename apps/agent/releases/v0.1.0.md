# Orvo Agent 0.1.0

The first public preview of Orvo Agent brings one-command host monitoring to
Orvo.

## Highlights

- Collects CPU, memory, load, disk, filesystem, network, paging, and process
  metrics using a curated OpenTelemetry Collector distribution.
- Enrolls automatically from the one-time command generated by the Orvo Hosts
  page.
- Uses a dedicated ingestion key per installation and keeps credentials outside
  the collector configuration file.
- Buffers telemetry in a persistent local queue during temporary network
  failures.
- Supports systemd-based Linux hosts on amd64 and arm64.
- Includes `status`, `doctor`, `dev`, and `uninstall` management commands.

## Known limitations

- Production installation currently supports Linux with systemd only.
- Automatic binary updates and staged rollout controls are planned but are not
  included in this release.
- macOS is supported for foreground development, not production installation.
