# Orvo Agent 0.1.3

This release adds safe in-place upgrades and makes the running agent version
visible to Orvo.

## Highlights

- Run `sudo orvo-agentctl upgrade` to install the latest stable agent release.
- Pin a specific newer release with `sudo orvo-agentctl upgrade --version X.Y.Z`.
- Verify release checksums before replacing either agent binary.
- Preserve the existing host identity, configuration, and ingestion key.
- Restore the previous version automatically if the upgraded service does not
  become healthy.
- Report the running version in host metrics so Orvo can show when an update is
  available.

## Upgrade notes

Install this release once using the command generated by Orvo. Future releases
can be installed directly with `sudo orvo-agentctl upgrade`.
