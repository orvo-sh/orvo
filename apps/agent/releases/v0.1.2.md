# Orvo Agent 0.1.2

This patch release fixes upgrades and repeat installations on hosts where the
agent service is already running.

## Fixes

- Restart the systemd service after enrollment so it loads the newly installed
  binary, configuration, and ingestion credentials.
- Prevent an older running agent process from continuing to export with stale
  credentials after a successful installation.

## Upgrade notes

Run the installation command generated by Orvo. The installer preserves the
host identity, enrolls the host, and restarts the service automatically.
