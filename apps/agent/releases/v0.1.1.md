# Orvo Agent 0.1.1

This patch release simplifies agent distribution by installing immutable,
version-pinned artifacts directly from GitHub Releases.

## Changes

- Publish `install.sh` as part of every agent GitHub Release.
- Require an explicit agent version during installation.
- Download the matching Linux archive and checksum file directly from the
  versioned GitHub Release.

## Upgrade notes

Existing installations are unaffected. New installation commands generated by
Orvo pin this release explicitly.
