# Overview

Orvo helps teams understand what changed in production by keeping logs, traces, metrics, alerts, and heartbeats in one product surface.

## How to use these docs

Start with installation if you are wiring Orvo into a new environment. Jump to the signals guides when you want to understand how to work with logs, traces, or metrics inside the product.

:::info
Use the sidebar categories to move between setup guides and signal-specific docs. The route path is built from the category and page slug.
:::

## What you should expect

The docs are organized around practical setup and investigation workflows rather than generic feature dumps. Each page is intended to get you from intent to action quickly.
