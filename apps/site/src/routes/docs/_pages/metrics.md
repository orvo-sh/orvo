# Metrics

Metrics are the fastest way to see whether the system is healthy overall before you dig into a specific request or event stream.

## Start broad, then narrow

Use metrics to answer whether the issue is isolated or systemic. Once you know the shape of the change, move into traces or logs to explain it.

## Compare trends around change points

Metrics are especially useful around deploys, traffic shifts, or capacity changes because they reveal whether the system is stabilizing or drifting.
